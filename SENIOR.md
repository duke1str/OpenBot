# Senior Integration

This fork is attached to the **COS Senior** architecture.

- Tenant package: `examples/senior/`
- Chief coordinator: `senior`
- Project agents: Pure Profit Health, Morrow & Grain, Luna & KK, Publishing & Growth
- Activation: set `TENANT_PACKAGE_DIR=../examples/senior` in the local `.env`.
- Governance: OpenBot provides controlled execution; existing Senior project rules remain authoritative.

Pure Profit remains **Alpaca PAPER-only** and the OpenBot diagnostic agent has no brokerage order execution authority.

See `examples/senior/README.md` for the command hierarchy and guardrails.
